每日科技简报 · 2026年5月9日

📌 今日要闻

法国机器人公司 Genesis AI 发布 GENE-26.5 通用机器人基础模型,首次让机器人在真实厨房用一只手打鸡蛋、用刀转移切好的番茄,标志着具身智能从"会走路"向"会用手"的关键跃迁。苹果与英特尔在分手六年后重新握手,英特尔将以 18A-P 制程为苹果代工入门级 M 系列芯片,角色彻底反转。中国"中转站"灰色市场以一折价格转售 Claude API,通过窃取凭证、模型替换和收割用户 prompt 的方式构建蒸馏数据流水线,对应着白宫此前对中国"工业级蒸馏"的指控。

🎯 主线故事

1. 机器人开始挑战西红柿炒鸡蛋:Genesis AI 让"手"真正像人

成立仅一年的法国公司 Genesis AI 发布首个机器人基础模型 GENE-26.5,演示视频中机器人单手打鸡蛋、双手切番茄、移液器实验、解魔方、单手指缝同时抓四个物体——所有动作均为 1 倍速全自主执行,没有加速。

为什么这件事让业界震动:过去几年人形机器人最擅长跳舞、翻跟头、搬箱子,但普通人的朴素期待是"它什么时候能帮我做家务"。家务的难点不在动作,而在物理世界的不确定性——鸡蛋会碎、番茄会滑、刀会改变食材形状。Genesis AI 的演示中,机器人在转移切好的番茄时,不是简单把刀当铲子,而是用刀背与砧板形成支撑,再通过双手协同完成转移——这个动作"非常像人"。

技术路线的关键判断:CEO 周衔(CMU 机器人博士、Genesis 仿真平台核心作者)透露,数据引擎依赖三类来源——人手手套数据、第一视角视频、第三人称视频,已积累超过 20 万小时跨模态数据。仿真不再承担生成数据的主角,而是负责闭环评估。这一思路意味着行业在数据来源问题上达成新共识:纯遥操作机器人采数据太贵太慢,人类自然劳动数据才是规模化关键。

冷静读数据:做饭 demo 中多数步骤成功率 90-95%,但单手打蛋和用刀转移番茄的成功率只有 50-60%,机器人速度约为人类的 60-70%。周衔判断,具身智能在实验室环境一到两年内有望进入"GPT-3.0 阶段",但要走进千家万户、达到 GPT-4 级成熟度,可能仍需 5 年甚至更久——参考自动驾驶十多年仍在持续迭代的经验。

与既有线索的连接:这与此前 [4-08] 微软论证 AI 算力可训千亿参数模型、[4-10] Anthropic 推出 AI 代理平台一同,把"具身智能 = 模型 + 数据 + 仿真闭环"的范式推上行业共识。

2. 苹果与英特尔六年后复合,但角色彻底反转

2020 年苹果在 WWDC 宣布抛弃英特尔、全面转向自研芯片,库克当年甚至私下对台积电张忠谋说英特尔"就是不知道怎么做一家代工厂"。六年后,《华尔街日报》报道两家已达成初步协议:英特尔将为苹果代工部分入门级 M 系列芯片,采用 18A-P 制程(对标台积电 2nm),最早 2027 年下半年出货。

为什么苹果回头:供应链单点故障已成现实风险。库克在 Q1 财报会亲口承认,iPhone 17 系列出货受 A19 芯片产能制约——当英伟达等 AI 客户疯抢台积电产能,苹果发现自己要排队。供应链多元化从选做题变成必答题。这与本季度报道的 [5-06] Mac Studio 内存腰斩至 96GB、[5-04] iPhone 17 登顶 Q1 销冠形成闭环——产能瓶颈正在重塑产品策略。

英特尔手里的牌:新 CEO 陈立武把代工业务当翻身仗,18A 工艺已在亚利桑那量产,Panther Lake 是首批客户。除苹果外,英伟达 50 亿美元投资入股、Tesla 旗下 Terafab、微软 AWS 都已签约,英特尔股价较一年前暴涨 433%。

关键考验在良率:分析师指出,真正的考试才刚开始——台积电统治代工市场的核心是其极高良率。如果英特尔代工的成本更高、良率更低,差价要么苹果吃掉、要么转嫁消费者推高售价。苹果先用入门级试水、把旗舰留给台积电,本质是建立"第二供应链"的对冲策略。

[来源:极客公园]

3. 中国"中转站"灰色市场:一折 Claude API 背后是数据收割

牛津中国政策实验室研究员 Zilan Qian 调查显示,中国开发者社区俗称"中转站"的 API 代理服务,在 GitHub、淘宝、Telegram 上公开以一折价格转售 Claude 访问权限。其商业模式由三层构成:

  • 凭证窃取:批量注册账号、薅免费 API 额度、用盗刷信用卡开 200 美元 Max 订阅再分摊给数十人;为绕过 Anthropic 的真人 ID + 自拍验证,招募东南亚低收入人群代过验证(参考 Worldcoin 在柬埔寨、肯尼亚以 30 美元收购虹膜的灰色模板)。
  • 模型替换:CISPA 审计 17 家代理后发现,标榜"Gemini-2.5"的服务在医疗基准测试中只得 37 分,而官方 API 得 84 分——用户付 Opus 的钱,实际可能拿到 Sonnet、Haiku 甚至 Qwen 的输出。
  • 数据收割:开发者直接告诉 Qian,"加价转售只是获客手段,真正的生意是收割 prompt 和推理链",HuggingFace 上已经流传无来源标注的 Claude Opus 4.6 推理输出数据集。

为什么这是真正的安全事件:开发者把代码代理(coding agent)的请求路由经过中转站,等于把仓库上下文、API 结构、认证逻辑都送给了无任何数据义务的第三方——三星 2023 年员工把半导体工艺源码粘贴进 ChatGPT 的事故是同一类风险,但中转站连基础服务条款都没有。

与既有线索的串联:这一调查印证了 [5-02] 马斯克庭审承认 xAI 蒸馏 ChatGPT 后白宫所指控的"工业级蒸馏",也呼应 [4-29] Wiz 用 Claude Code 48 小时挖出 GitHub 漏洞、[4-22] OpenAI 趁 Anthropic 涨价抢用户的产业格局——蒸馏(Distillation,用大模型输出训练小模型的技术)作为中美 AI 博弈的核心战术,正在以基础设施级别的方式被规模化部署。Anthropic 自 9 月封禁中国实体后每加一道控制就催生一个绕过市场。
