主要故事

一、Linux 内核九年漏洞 CVE-2026-46333:AI 挖洞时代的开幕式

Qualys 威胁研究部今天公开披露了 Linux 内核的逻辑漏洞 CVE-2026-46333,缺陷自 2016 年 11 月 v4.10-rc1 起就潜伏在主线代码里,影响几乎所有主流发行版的默认安装。

技术细节:漏洞出现在一个特权进程"丢弃凭据"(dropping credentials)的极短时间窗口里。本应通过 dumpable 标志关闭 ptrace 通道,但内核里有一段路径漏掉了这个保护。攻击者只要配合 pidfd_getfd() 系统调用(2020 年随 v5.6-rc1 加入),就能从这个濒死的特权进程那里"偷"走已经打开的文件描述符,并在自己的 uid 下复用。

后果是教科书级别的灾难——任何低权限 shell 都能:

  • 读取 /etc/shadow(系统密码哈希)
  • 窃取 /etc/ssh 下的 SSH 主机私钥
  • 通过劫持的 dbus 连接以 root 身份对 systemd 发号施令

也就是说,钓鱼拿到的开发者账号、受限 CI runner、低权限服务账号、多租户共享主机,任何一个落脚点都直接等于完整主机被拿下。"非特权立足点"与"完全控制"之间那条惯常的鸿沟,在这个 bug 面前直接坍塌。

更值得品味的是披露节奏。Qualys 5 月 11 日上报,内核安全组三天内修补提交,5 月 14 日公开 commit。然后短短几天内,就有独立研究者从公开 commit 反推出可用 exploit 并公开。Qualys 不得不提前放出完整 advisory,因为"公开图景已经不完整且不均匀"。

这就引出今天的真正主题——AI 挖洞正在重写内核安全产业的节奏。同一天,The Register 把 Dirty Frag、Copy Fail、Fragnesia 这一组最近的 Linux 漏洞合在一起观察:

  • Linus Torvalds 在明尼苏达 Open Source Summit 直接修改了 Linux 安全披露的潜规则。过去内核社区会"悄悄通知发行版升级",几乎没人能复盘出究竟修了什么;现在他承认"上周我们修了一个 bug,三小时内就有博客分析这个 fix 的安全含义"。他的新原则是:"AI 检测到的漏洞按定义就不是秘密,放在私有列表上就是浪费所有人时间",而且"你用 AI 发现它,另外 100 个人也会用 AI 发现它"。
  • CloudLinux CEO Igor Seletskiy 评论说,过去一年通常只有一两个跨发行版的内核级提权漏洞,现在一周之内出现两个,企业可能要回归"每周重启服务器"的节奏。
  • Google 威胁情报组的数据更加触目惊心:漏洞平均利用时间(TTE)从 2018 年的 63 天,降到 2024 年的 -1 天,2025 年预计是 -7 天——负数意味着漏洞在补丁发布之前就已经被利用。

为什么意义重大?Torvalds 提醒:别幸灾乐祸觉得只有 Linux 倒霉,"如果你觉得 AI 不能逆向闭源代码,那你要大吃一惊——而且闭源更糟,AI 帮你找漏洞却帮不了你修"。RedHat CTO Chris Wright 借势喊话:是时候把 SELinux 从 permissive 模式正式切到 enforcing(强制)模式了。

为什么重要:这不是一个普通 LPE。这是 AI 漏洞挖掘从"加速器"变成"颠覆者"的转折——产业第一次需要假设"任何代码 AI 都已经读过、任何 bug AI 都已经看过"。Linux 安全治理的整套流程(私有披露、协调发布、负责任公布)在 AI 速度面前正在结构性失效,这与我们之前持续报道的 [Mythos 模型协助挖洞、Anthropic NCSC 警告"AI 补丁海啸"] 完全在同一条曲线上。

二、DeepSeek V4 Pro 永久降价 75%:大模型 API 价格战的"地板模式"

DeepSeek 今天把 V4 Pro 的官方定价永久调降到原价的四分之一——原本到 5 月 31 日截止的"75% 促销"直接转为长期价格。具体区间:每百万 tokens 由 $0.0145–$3.48 降到 $0.003625–$0.87(输入/输出按区间)。

这是 DeepSeek 4 月发布 V4 系列后(主打"百万级 context 的高性价比时代")的第二次定价动作,把"性价比"的护城河挖到了行业历史最低点。对比同期:OpenAI GPT-5、Google Gemini 3.5 Flash 都将面对一个把价格曲线垂直拉下来的对手。Anthropic 之前曾指控 DeepSeek "蒸馏攻击",这次价格再砍一刀,很可能会把矛盾再次激化。

为什么重要:此前我们追踪过的"中国大模型估值齐飞"(DeepSeek 拟募 500 亿)和"算力分叉走向多极"两个主线,在这里合流——融资充足 + 算力自主 + 价格亏本拉新,是中国厂商对抗 CUDA 系阵营的统一战法。对企业用户来说,意味着"百万 token 工作流"的成本不再是门槛;对 Anthropic、OpenAI 来说,Token 经济的天花板正在被对手从底部压下来。

三、三星罢工"内战"升级:HBM4 供货悬在 607% vs 50% 的奖金差上

我们 5 月 18 日报道的三星罢工风险并未随工会临时协议平息,反而蔓延到了关键的封测部门。

数字一目了然:内存(memory)部门员工奖金约 6 亿韩元(约 40 万美元);DX 部门(手机、电视、家电)只有 600 万韩元(约 4000 美元)——100 倍差距。结果是,代工(Foundry)和 TSP(Test & Package)部门"会议被集体取消","重大项目决策完全停摆"。

这对供应链的现实冲击很具体:TSP 负责 HBM 后段封测,直接关系到三星给英伟达下一代 Rubin AI 加速器的 HBM4 出货。前线工程师怠工——加之 DX 工会已经向法院申请禁制令阻止以内存工会为主体的集体谈判——意味着三星可能在最关键的 AI 内存交付窗口出现裂痕。

5 月 27 日工会投票表决前,如果非内存部门 4.3 万人投出否决票,这份"利润分享"协议可能整体崩盘。叠加我们 4 月报道的全球 DRAM 持续短缺(预计延续至 2027-2030)和今天 Micron 1α 弗吉尼亚投产(见下文),AI 内存版图正在被一场"内部薪酬不公"加剧扭曲。

四、AI Token 危机继续发酵:微软内部停掉 Claude Code

The Verge 报道,微软正在推动员工从 Claude Code 切换到自家 Copilot CLI。表面理由是"用自家工具",实际原因是 Claude Code 的成本随使用量飙升已经压不住。这与我们 5 月 18 日报道的"Token 经济成 KPI"事件直接相关。

数据更直观:Agentic AI(智能体模式)消耗的 token 可能是普通 LLM 查询的 1000 倍——因为它要多步推理、调用工具、循环执行。OpenClaw 作者 Peter Steinberger 自爆单月 token 账单超过 130 万美元。Jensen Huang 此前喊话"工程师每年至少要用掉年薪一半的 token",甚至呵斥不让员工用 AI 的经理"你疯了吗"。结果就是 Amazon、微软、Meta 等公司内部都出现了员工为完成"AI 使用 KPI"而主动刷 token(tokenmaxxing)的怪相。

经典的杰文斯悖论(Jevons Paradox,即:技术越高效,使用反而越多,总消耗反而上升)在 AI 上再次上演。值得追问的是:当用 AI 比雇人更贵,但 KPI 又强迫用 AI,这场"AI 替代人力"的叙事还能撑多久?

五、PLA Daily 罕见长文:解放军内部如何认真讨论 AGI 战争

LessWrong 翻译了 2025 年 1 月《解放军报》第 7 版的整版长文《AGI 带来的战争思考》,作者是国防大学联合作战学院的荣明、胡晓峰(后者为陆军少将、首席科学家级人物,毛主席亲自签发军功嘉奖)。这是西方第一次完整看到 PLA 体系内部关于 AGI(通用人工智能,达到人类智能水平的 AI)战争意义的系统讨论。

文章核心立场可以总结为四点:

  1. AGI 不只是"赋能"——颠覆性远超信息化与机械化,旧的网络战曾被夸大,但 AGI 不同。
  2. AGI 不会让战争消失——反而会因"AI 进攻优势"和"先发制人最优"打破攻防平衡,触发新军备竞赛。文章引用了 Cornell(实为 arXiv 上的斯坦福/佐治亚理工/Hoover 联合研究)关于大模型在兵棋推演中"突然发动核打击"的结论。
  3. AGI 不会是终极威慑——它快、果断,但缺乏共情,战略迂回空间被极致压缩;并引用 Hinton 的话"从未见过低智能控制高智能的案例"。
  4. AGI 不会改变战争本质——但会改变战争形式;尤瓦尔·赫拉利的判断被引用:"会讲故事的 AI 将改变人类历史走向",通过深伪、舆论操控,可能让战争意志被恶意操控者掌握,小国"在开战之前就被结束"。

为什么重要:西方主流分析(剑桥 Ó hÉigeartaigh、RAND Kyle Chan)长期认为中国官方并不把 AGI 当战略目标,而是"通用 AI 产业化"。但这篇 PLA 长文显示,至少在 2025 年初,PLA 顶层学术机构已经把 AGI 当作具有变革性、潜在失控风险的战略技术来推理——包括失控、威慑崩溃、文明扰乱等议题。这与中国 AI 实验室(DeepSeek、智谱)的"AGI 是终点"宣言形成耦合,提醒西方:中美 AGI 竞赛的战略想定,可能比"GPU 出口管制"的辩论要深得多。

咱们说回另一个今天爆出的大新闻，DeepSeek 把 V4 Pro 的价格永久砍掉了百分之七十五。原本到5月31号截止的促销，直接转成长期价格。每百万 tokens 的输入输出价格，从原来的最高3.48美元，降到了最高8毛7。这是什么操作？这是把全球大模型的 API 价格战拉到了地板模式。

你想啊，OpenAI 的 GPT-5、Google 的 Gemini 3.5 Flash，现在都要面对一个把价格曲线直接垂直拉下来的对手。Anthropic 之前还指控过 DeepSeek 蒸馏攻击，这次再砍一刀，矛盾恐怕要再次激化。但是这件事最值得品味的，是它跟另一条新闻的合流。中国大模型最近估值齐飞，DeepSeek 据传要募500亿，算力也在走向自主。融资充足、算力自主、价格亏本拉新，这就是中国厂商对抗 CUDA 阵营的统一战法。对企业用户来说，百万 token 工作流的成本不再是门槛。对 OpenAI 和 Anthropic 来说，Token 经济的天花板正在被对手从底部死死压下来。

这里就引出了今天第三个重磅故事，AI 算力的账单危机正在撕裂大厂。The Verge 今天报道，微软正在内部强推员工从 Claude Code 切换到自家的 Copilot CLI。表面理由是用自家工具，实际原因是 Claude Code 的成本随使用量飙升已经压不住了。

数据有多吓人？Agent 模式消耗的 token，可能是普通 LLM 查询的1000倍，因为它要多步推理、调用工具、循环执行。OpenClaw 的作者 Peter Steinberger 自己爆料，单月 token 账单超过130万美元。一个人。一个月。130万美元。英伟达的 Jensen Huang 之前还喊话，说工程师每年至少要用掉年薪一半的 token，甚至呵斥不让员工用 AI 的经理"你疯了吗"。结果就出现了一个非常魔幻的现象，Amazon、微软、Meta 内部都有员工为了完成 AI 使用 KPI，主动去刷 token，这个新词儿叫 tokenmaxxing。

这就是经典的杰文斯悖论在 AI 上的再次上演。技术越高效，使用反而越多，总消耗反而上升。我跟你说，这里有个特别值得追问的问题。当用 AI 比雇人更贵，但 KPI 又强迫你必须用 AI，这场"AI 替代人力"的叙事，还能撑多久？

咱们接着说硬件圈。三星的罢工内战今天升级了，而且直接威胁到了英伟达下一代 Rubin AI 加速器的 HBM4 供货。数字一看就明白，三星内存部门员工的奖金大约6亿韩元，折合40万美元。但 DX 部门，就是手机电视家电那块，只有600万韩元，4000美元。100倍的差距。结果代工部门和封测部门集体怠工，会议被取消，重大项目决策完全停摆。

最关键的是封测部门 TSP，它直接负责 HBM 的后段封装测试，关系到三星给英伟达 Rubin 的 HBM4 出货。前线工程师怠工是什么概念？意味着三星可能在最关键的 AI 内存交付窗口出现裂痕。5月27号工会投票，如果非内存部门4.3万人投了否决票，整个利润分享协议就可能全盘崩盘。叠加全球 DRAM 持续短缺要延续到2027到2030年，AI 内存的版图正在被一场"内部薪酬不公"扭曲。

最后我想跟你聊一个很有意思的发现。LessWrong 翻译了2025年1月《解放军报》第七版的整版长文，标题叫《AGI 带来的战争思考》。作者是国防大学联合作战学院的荣明和胡晓峰，胡晓峰是陆军少将级别的首席科学家。这是西方第一次完整看到解放军体系内部，关于 AGI 战争意义的系统讨论。

文章核心四个观点。第一，AGI 不只是赋能，它的颠覆性远超信息化和机械化。第二，AGI 不会让战争消失，反而因为 AI 进攻优势和先发制人最优，会打破攻防平衡，触发新军备竞赛。文章甚至引用了大模型在兵棋推演中"突然发动核打击"的研究结论。第三，AGI 不会是终极威慑，它快、果断，但缺乏共情，战略迂回空间被极致压缩。还引用了 Hinton 的话，"从未见过低智能控制高智能的案例"。第四，AGI 不会改变战争本质，但会改变战争形式。赫拉利的判断被引用，"会讲故事的 AI 将改变人类历史走向"，通过深伪和舆论操控，小国可能在开战之前就被结束。

为什么这个值得关注？因为西方主流分析长期认为，中国官方并不把 AGI 当战略目标，而是把它当通用 AI 产业化。但这篇长文显示，至少在2025年初，解放军顶层学术机构已经把 AGI 当作具有变革性、潜在失控风险的战略技术来推理了。这跟 DeepSeek、智谱这些 AI 实验室的"AGI 是终点"宣言形成了耦合。中美 AGI 竞赛的战略想定，可能比 GPU 出口管制的辩论要深得多。
